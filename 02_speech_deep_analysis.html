梁文鋒內部講話 · 深度拆解

原始檔：01_speech.md（大宇 @BTCdayu 精校整理稿）
拆解日期：2026-07-24
定位：把一場「融資後內部對齊 / 投資者溝通」講話，拆成可複用的戰略心智模型
對象：想理解 DeepSeek 為什麼這樣玩、以及這些邏輯對個人 AI 基建有什麼啟發的人

0. 這篇講話到底是什麼

這不是 PR 稿，也不是產品發布會。

它更像：

層 內容
表面 融資後向內部/投資人解釋：我們是誰、怎麼賺錢、下一步打什麼
中層 用一套自洽的商業哲學，解釋開源、定價、C端/B端、算力、組織
深層 在「AI 可能佔 GDP 巨大份額」的歷史尺度上，定義 剋制即戰略

讀這篇的正確姿勢：不要當雞湯，當 系統設計文件 讀。
梁文鋒反覆在回答同一個架構問題：

當一件事大到無法獨佔時，什麼樣的目標函數、組織形態、利益分配，能最大化「做成」的機率？

1. 一句話總綱

DeepSeek 的作業系統：

願景驅動（善意 + AGI）
    ↓
剋制（開源 / 合理利潤 / 不搶芝麻）
    ↓
聚焦主線（LM → CoT → Agent → 持續學習 → 自我迭代 → 具身）
    ↓
副產品商業化（C端 / B端 / API 都是路上的產出，不是目標）
    ↓
唯一核心利益：團隊穩定
    ↓
用有限算力做極致效率 + 等待資源擴大

可再壓縮成四個字：

少拿，多成。

或更工程化：

Maximize P(AGI) subject to 合理利潤 & 團隊不散，而不是 Maximize ARR。

2. 心智模型地圖（先建立座標）

2.1 五個關鍵槓桿

槓桿 梁的定義 反直覺點
願景 組織人的真實運行方式，不是牆上標語 無 KPI、無成文願景，靠做事方式對齊
剋制 戰略，不是道德表演 越剋制越容易做成；拿得多的會被拿得少的打敗
開源 願景的必然 + 商業上的可行解 在「只賺六倍利潤」前提下，開源不傷商業
主線 LM → CoT → Agent → 持續學習 → 奇點 → 具身 影片生成、世界模型當前不在主線
團隊穩定 唯一不可退讓的核心利益 錢、卡、資源都是時間問題；人散了才是真風險

2.2 三組「假對立」被他拆掉

很多人預設對立，他用條件句拆掉：

  1. 開源 vs 商業化
    → 衝突發生在「想賺一百倍利潤」時；只賺合理利潤（約六倍 / 十個月回本）時不衝突。

  2. 做 AGI vs 做 C/B 端
    → C/B 是 AGI 路上的副產品；站在高位做低位是降維打擊。

  3. 善意 vs 利益
    → 歷史經驗：善意/開源/幫助對手並沒有讓他少拿東西，反而可能加分。

2.3 目標函數對照

典型大廠/競品（他眼中） DeepSeek
Max(ARR / 使用者 / 份額) Max(做成 AGI 的機率)
產品閉環、搶流量 技術主線、副產變現
KPI + 組織驅動 願景 + 共識驅動
閉源護城河 開源 + 成本壁壘 + 時間差
什麼錢都賺 只撿芝麻、不擋西瓜

3. 分章精讀（說了什麼 → 真正在說什麼 → 可抽取原則）

第一章：初衷與願景

說了什麼

  • 最早幾十人不是奔上市/賺錢來的；若奔這個，不會來。
  • 對世界的「善意」是組織原則。
  • 引傑克·韋爾奇：公司最重要的是願景；管理大公司靠願景，不靠規章制度。
  • 願景 = 怎麼做，不是怎麼說；甚至沒成文，存在於方法與態度裡。
  • 沒有考核，只有願景；組織幾乎靠願景驅動。

真正在說什麼

這是在建立 合法性與篩選機制：

  1. 合法性：後面所有「反商業直覺」的決策（開源、降價、不搶用戶）都要回到這個初衷才說得通。
  2. 篩選：願景本身就是 HR 過濾器——來的人不是利潤最大化型，流失會低。
  3. 治理：用「共享方向」替代「KPI 系統」，適合早期研究型組織，但人一多會有代價（他後文承認要補組織架構）。

可抽取原則

原則 A：目標函數決定組織形態。
若目標是 AGI 機率最大化，KPI 化會扭曲行為（搶短線、囤使用者、閉源護城河）。

對讀者的提醒

  • 「沒有組織」是階段優勢，不是永恆真理。後文他明確：人擴大後必須改——有的部門要嚴謹層級，有的保持鬆散。
  • 願景驅動的風險：理解不一致、協調成本、無法規模化複製。他已在補。

第二章：為什麼堅持開源

說了什麼

  • 開源是願景的要求（對比：有的公司開源「被迫」）。
  • 歷史：軟體開源常毀商業（市場只有幾十億刀）；AI 不同——最終可能占人類 GDP 很大一塊，無法獨佔。
  • 想獨佔 → 會被歷史拋棄、遇到阻力；需要機制限制自己利益上限 → 剋制。
  • 敘事偏好：一群平凡人做不平凡的事（非天才敘事）。

真正在說什麼

開源在這裡是 三件套：

層 含義
價值觀層 善意、分享、組織人
歷史觀層 過大的市場不能獨佔，分享是生存條件
競爭策略層 剋制讓路徑更順、阻力更小、機率更大

關鍵洞見：

不是「開源也能賺錢」，而是「想做成這麼大的事，你必須設計一個拿得少的機制」。

可抽取原則

原則 B：市場規模決定獨佔可行性。
市場小 → 開源傷商業；市場極大 → 獨佔反而是死路。

原則 C：剋制 = 提高 P(success) 的策略，不是讓利表演。

第三章：API 定價與「十個月回本」

說了什麼

  • 合理利潤：買裝置約 十個月收回成本（財務攤銷 3–5 年，商業上 10 個月夠了）。
  • 不是利潤最大化：該價位需求幾乎無彈性——漲價一倍，收入近一倍，用量差不多。
  • 故事：某模型先定高價（團隊不爽）→ 降到 1/4 → 群裡歡呼。動力是「大家都用得起」。
  • 競品不會為你降價歡呼（ARR 掉一半）。
  • 再降價：需求彈性已盡，公司收入不增、社會幸福也不顯著增 → 不必再降。
  • 成本最佳化是真壁壘：阿里/騰訊達不到同樣成本。

真正在說什麼

定價公式背後是 身份認同 + 競爭壁壘 + 彈性經濟學：

定價 = 裝置成本 / 10個月
     ≈ 約 6× 利潤（他後文換算）

三層作用：

  1. 對內：員工成就感、凝聚力（降價歡呼是文化證據）。
  2. 對外：使用者滿意、雙贏敘事、道德高地。
  3. 對競爭：第三方獨立部署成本做不到 → 開源了也搶不走利潤。

「需求無彈性」是關鍵假設：
當前價位已是「人人用得起」區間 → 再降無增量 → 再漲則損願景與長期機率。

可抽取原則

原則 D：定價對齊願景時，價格是文化工具，不只是收入工具。

原則 E：成本壁壘 > 閉源壁壘（在他們的假設下）。
別人就算拿到權重，也做不到你的部署成本。

張力 / 要追問的

  • 「無彈性」是階段事實還是永久事實？Agent 爆發後需求曲線可能變。
  • 六倍利潤在公眾敘事裡會被攻擊「還是很貴」；他已承認還有最佳化與降價空間。

第四章：不搶用戶，不撿光芝麻

說了什麼

  • 去年春節流量暴漲：服務好使用者，但不搶變現、不做下一個位元組/騰訊。
  • 隱喻：前面是芝麻，後面是西瓜（AGI）。
  • 去年沒做大 C 端「可能是對的」。
  • C 端日活、今年 B 端 ARR 都會「隨手撿」，但不是第一優先。
  • 若 AI ARR 到數億刀可 cover 研發；十億刀量級可現金流回正——會做，不當主目標。

真正在說什麼

這是 機會成本管理 與 注意力分配：

動作 收益型別 優先順序
搶 C 端超級 App 短中期商業 低（芝麻）
做 To B ARR 中期現金流 中（要做好，非第一）
推 AGI 主線 長期巨大 高（西瓜）

「隨手撿」= 保持期權，不押注、不all-in。

可抽取原則

原則 F：有更大期權時，區域性最優會毀掉全域性最優。
去年若重金砸 C 端，可能換來「大一點的芝麻」，失去組織與技術焦點。

第五章：開源再論 —— 六倍利潤下無衝突

說了什麼

  • 最強模型也可能開源；看不到閉源好處（點位元組）。
  • 開源門檻仍極高：部署 + 極低成本很難複製。
  • 創業公司規模有 sweet spot：太小無力，太大難組織。
  • 十個月回本 ≈ 六倍利潤 → 第三方無利可圖 → 開源不影響收入。
  • 想賺一百倍 → 開源會破壞。
  • 不加班、不難：因在別處大量捨棄。
  • 希望別人部署成功；擔心的是他們部署差、效果差。
  • 開源模型 = 自部署模型，沒有雙軌縮水版。

真正在說什麼

商業模式的充要條件寫得很清楚：

IF 利潤倍數 ≤ 合理區間（約 6×）
AND 自有成本 << 第三方複製成本
THEN 開源 ⟂ 收入

護城河排序（他隱含的）：

  1. 訓練與系統最佳化能力（成本）
  2. 組織與願景（人）
  3. 時間領先
  4. ~~權重保密~~（不依賴）

「我們根本都不用加班」= 聚焦帶來的鬆弛，不是輕鬆的活本身簡單。

可抽取原則

原則 G：護城河要與目標函數匹配。
目標是做成 AGI 而非抽租 → 權重保密不是最優護城河；成本與速度才是。

第六章：AGI 技術路線圖（全篇技術核心）

說了什麼 —— 階梯模型

語言模型（基礎）
    ↓
CoT / 思維鏈（去年階梯：智慧上限躍遷）
    ↓
Agent（今年階梯：能力範圍擴大）
    ↓
持續學習 / 「學習去學習」（下一個瓶頸）
    ↓
自我迭代「奇點」（實為漸進非線性過程）
    ↓
具身智慧（進現實世界：家務、養老）

關鍵論證：為什麼現在 AI 替不了員工

人類員工 當前 AI
入職 2 個月持續學習公司語境 無持續學習
「叫小王來」自動有 grounding 必須喂完整上下文
上下文可積累 侷限上下文內可超人，跨場景不行

結論：差的是 持續學習，不是單點智力。
在完整上下文 + 指令下，當前 AI 已可超人類；前提極難滿足。

為什麼這條路線「輕鬆」

  • 每步新東西少，前序技術可加速後序。
  • 奇點後具身可由模型自己做 → 人不用苦做具身優先。
  • 反過來先具身 = 苦活。

奇點澄清

  • 不是突變臨界點，是 漸進 + 非線性（AI 加速 AI 研究）。
  • 習慣叫奇點，是預言家語言殘留。

真正在說什麼

這是 資源分配的技術憲法：

  • 在主線 → 做（甚至最強模型也可開源）。
  • 不在主線 → 不做，哪怕是好生意（影片生成）。
  • 世界模型：現階段與智慧上限關係不大（公司判斷，非普世真理）。

可抽取原則

原則 H：路線圖的價值是減少無效工作。
正確順序讓你「不用加班」；錯誤順序讓你人力密集、資料密集、價效比低。

原則 I：當前瓶頸不是「更聰明的單次推理」，是「能像員工一樣積累語境的學習」。

第七章：降維打擊 —— C/B 是副產品

說了什麼

  • 行業現實：去年搶 Chatbot/C 端，今年搶 To B。
  • 公司真正關心：AGI 路線與技術突破。
  • 悖論：越想要越得不到；不太在意反而容易得到。
  • 站在 AGI 高位做應用 = 降維；幾個人維護 API，無銷售無客服，使用者自己來。
  • AGI 願景凝聚更優秀的人 → 組織優勢 → 也是降維。
  • 春節爆火不在劇本；沒去搶的人牽走了流量。

真正在說什麼

兩個「降維」：

  1. 技術降維：高通用能力自然覆蓋低層應用。
  2. 組織降維：更強願景 → 更好人才結構 → 產品戰隱性勝出。

「副產品商業化」是反諮詢公司邏輯：
不是先找 PMF 再養技術，而是 技術主線自動產出 PMF。

可抽取原則

原則 J：當你的主目標在更高抽象層時，低層市場可用「維護級精力」收取。

風險

  • 若技術主線停滯，副產品組織能力可能不夠（他後文保底：凍結核心技術也能靠 API 活）。

第八章：唯一核心利益 —— 團隊穩定

說了什麼

  • 處處剋制，但 唯一不可退讓：團隊穩定。
  • 人在 → AGI 一定成，只是早晚；錢與資源不是真瓶頸。
  • 融資後期權緩解風險；老員工穩 → 其他人不易走。
  • 人才流動同行中偏低，仍是最大挑戰。
  • 對外：只做 AGI 主線；願賦能對手（阿里、智譜、月之暗面）；3D/影片/世界模型不自己做但可幫忙。
  • 善意沒有讓商業變差，可能加分。

真正在說什麼

風險排序：

團隊離散  >>  技術挫折  >>  資金  >>  短期商業得失

「幫助競爭對手」在邏輯上自洽：
開源邊界本就要說清楚；利益函數是 AGI 機率而非份額 → 對手變強不必然傷害你。

可抽取原則

原則 K：對研究型 AGI 公司，人才網路的連通性是唯一生存條件；其他都可對沖。

第九章：算力 —— 中美差距只在資源

說了什麼

  • 約 2 萬張 H 等效（大量剛到）；激進擴卡，幾乎全是英偉達。
  • 策略：合理價格內能買多少買多少；半年花光錢 = 理想（錢變卡 > 銀行存款 2%）。
  • 卡：十個月回本；怕買不到，不怕花太快。
  • 人差距小（同一批中國人，去留近似隨機）；人才差距本質是算力差距（實驗次數）。
  • 美國最大模型 ~800B 啟用；國內還在 幾十 B 量級。
  • 訓同規模：約 5 萬 GB300 或華為 950 二十萬卡（僅訓練，不含研究）。
  • 現實：先把能訓得起的幾十 B 做好 → 再 150/250B。
  • 問題「目前基本無解」。

真正在說什麼

戰略收縮：

不在無法企及的規模上硬剛；在可支付規模上把效率與研究做透，等資源曲線上來。

差距傳導鏈：

算力不足 → 實驗不足 → 人才成長慢 → 模型能力差 → 應用差

全部可還原為資源。

可抽取原則

原則 L：在硬約束下，最優策略是「可訓練尺度上的深度」而非「不可支撐尺度上的虛榮」。

第十章：終局差距

最終三差：

  1. 成本（第一，最硬壁壘）
  2. 時間（早晚幾個月）
  3. 用戶體驗（有粘性，但非本質）

含義：長期看模型能力會趨同；誰便宜、誰先到、誰好用一點 決定勝負。
這與開源、剋制、效率執唸完全閉環。

第十一章：商業化態度

說了什麼

  • 一直在商業化，但從不以商業化為目標。
  • 現在花精力做產品線/電商廣告本地生活 = 浪費（變化太快，產品生命週期短）。
  • 離「徹底轉向商業化」很遠。
  • 希望商業機會留給生態夥伴。
  • 融資精心選利益一致方。
  • 決策機制：尋求共識，非一人獨斷；權威建立在共識上。
  • 精力主要在 DeepSeek。

可抽取原則

原則 M：在正規化快速遷移期，產品路線圖的半衰期極短；技術下限上移的 ROI 更高。

第十二章：模型差距與全球分工

  • 比效果必須 同成本 比較。
  • Anthropic 超 OpenAI = 階段現象；OpenAI/Google 交替上升；Anthropic 效率高、燒錢少；Code Agent 優勢非永久碾壓。
  • 中國角色：或類似其他產業——產量最大、價格系統性更低。

第十三章：國產晶片與 TileLang（工程高信號）

CUDA 護城河在瓦解的三原因

  1. AI 寫程式碼 → 重建生態變容易
  2. TileLang 類高階語言 → 可快速重寫運算元棧
  3. 計算卡市場 > 遊戲卡 → 專用晶片與 CUDA/遊戲血統解耦

DeepSeek 實踐

  • V3：用英偉達卡，但 不用英偉達生態，走 TileLang 編譯器棧。
  • 華為路徑：把同一套在華為卡上重做；深參與生態，主攻高階語言編譯器。
  • 判斷：一年內可驗證「國產生態沒問題」；剩餘是 產能。
  • 華為 950 超節點：任務可平替 GB200/300；價格貴 50%–100% 可接受。
  • 晶片差距敘事：生態差消失後 ≈ 四倍 + 兩年（硬體代際）。
  • 不做垂直整合上游（不造發電機，只運營電廠）；自建叢集要，自研晶片看收益。

可抽取原則

原則 N：當 AI 能生成基礎設施程式碼時，軟體生態護城河折舊加速。

第十四章：多模態、Scaling、低成本

  • 多模態：C 端重要；對智慧是 元件（如搜尋），非主線本體。V4+ 原生多模態會做。
  • 信 Scaling；牆還遠；卡住的是算力不是信念。模型大小 = 資源可承受，不是「夠了」。
  • 下一代必須有 持續學習 才叫真正下一代；此前拼成本/效果/速度。
  • 在乎效率的原因：願景 + 同理心（普通人知道花錢）；且效率高 → 同樣卡訓更大模型。商業公司常無動力追極致低價。

第十五章：拿得少的人打敗拿得多的人（全文哲學核）

邏輯鏈：

若 A 想拿 GDP 的 5%
B 說我只拿 1% 且做得一樣好
→ B 打敗 A

C 說我只拿 0.1%
→ C 又可能打敗 B

但有下界：拿太少 → 商業不成立 → 死。
均衡：合理利潤帶。

更深一層：

甚至不用真拿多——願景若是拿得多，就已經輸了（路徑更難、敵人更多）。

這解釋了：

  • OpenAI 式「壟斷世界」敘事會招挑戰者
  • 中國（及更剋制者）可用「拿更少」提供同等服務
  • DeepSeek 定價與開源不是慈善，是 博弈論均衡選擇

可抽取原則

原則 O（元原則）：在超大蛋糕上，貪婪的目標函數會系統性增加阻力。

第十六章：組織方式

兩條線

線 含義 約束
從上到下（正式） 集體任務如發 V4，分工協同 最好 不超過個人時間 50%
從下到上 無人管、無 KPI，自己探索 算力能支援就做

不加班兩原因：

  1. 研究需要鬆弛
  2. 極度聚焦 → 事情少

產品不完善也不補 = 文化選擇。

可抽取原則

原則 P：研究組織需要「半計劃半混沌」；正式工作吃掉全部頻寬會殺死探索。

4. 問答環節：高信號補充

4.1 持續學習

  • 不是單一技術，是一類問題；多路徑摸索，全球都未「做通」。
  • 資源觀：不佔卡、不佔人編制——「摸獎」：門檻低、靠想法。
  • 內部敘事：模型先對自己有用（加速 DeepSeek 研發）→ 再對使用者有用。
    這是實現 AGI 最快路徑。
  • 先持續學習 → 通用智慧變容易；否則人工堆通用智慧是苦力。

4.2 中美敘事（他給的可傳播版本）

落後 1–2 年，用約 1/20 算力把事情做出來。
目標：縮短到 6 個月/3 個月；區域性超越；全面超越不現實。

4.3 生態與產業收斂

  • 人才荒 = 階段性（2–3 年可緩解）。
  • 中國基模公司 過多，資源分散；最終收斂到約「兩家大 + 兩家小」量級就夠價格競爭。
  • 高利潤率不符合客觀規律 → 會擠出偽需求玩家。

4.4 資料與標註

  • 資料 ≈ 模型一半。
  • 中國 無高階標註成本優勢；標不起美國那套。
  • 現狀：一半核心研究員在標資料；先標便宜的。
  • 幻覺：可 post-training 改善，偏產品問題，非主線重點。
  • 高質量資料：瓶頸是 時間 不是錢；一年內國內可顯著改善。

4.5 應用優先順序

  • 現階段最合理：全力通用 Agent，尤其 Coding Agent。
  • 金融/醫療等縱向 Agent 優先順序更低。

4.6 資本市場 vs 純粹科研

  • 要都要：B 端數億刀 + C 端使用者 → 接近淨利潤可能不遠。
  • 保底：技術凍結也能靠賣 API 撐上市公司級別。
  • 本質仍是公司（非 Bell Labs）：政府不給錢，要活；有利潤外追求的公司反而可能商業更好。

4.7 發版與規模

  • 舒適節奏：2–3 個月一版。
  • 50B 啟用：與當前開源波次差距不大；與未公開超大模型差距大。
  • 150B：樂觀今年底可開始訓，實際更可能更晚。

4.8 TileLang 效率

  • 大幅提高 開發效率；對硬體執行效率損失約 1–2%，可接受。
  • 另有專案：用 AI 寫 TileLang。

4.9 品味 / taste

  • AI 不缺品位與直覺；缺持續學習。

4.10 組織演進

  • 過去極度分散（近乎無架構）。
  • 人擴大必須改：部分嚴謹層級，部分保持扁平；已經在做。
